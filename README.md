## How it works

- Fetches the public JUNGOL profile for account `143157`
- Reads the current tier, rank, solved count, and RV
- Embeds the official JUNGOL tier SVG inside the generated card
- Updates `jungol-card.svg` every 6 hours with GitHub Actions
- Commits only when the rendered card actually changes
